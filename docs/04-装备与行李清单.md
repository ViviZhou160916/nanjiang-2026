# 04 · 装备与行李清单

> 核心原则：**洋葱式分层穿衣**。喀什白天 20°C+（短袖/薄长袖），塔县夜间 -5°C 以下（羽绒服），N39 沙漠昼夜温差 20°C+。
> 行李结构建议：1 个 20—24 寸行李箱（放后备箱）+ 1 个背包（随身）。

## 证件与票务（随身包，全程不离身）

- [ ] 身份证（全程安检频繁，放随手可取处）
- [ ] **边防证**（塔县/克州必需：前往地写「喀什地区」+「克州地区」；户籍地或 12367 APP 均可办）
- [ ] 机票行程单（电子版截图+纸质备份）
- [ ] 驾照 + 驾驶人身份证（自驾必备，2 名司机都带）
- [ ] 学生/教师等优惠证件
- [ ] 证件照 1—2 张（备用）
- [ ] 少量现金 300—500 元/人

## 衣物（分层系统）

- [ ] 速干内层：短袖 T 恤 ×2、薄长袖 ×2
- [ ] 保暖中层：抓绒/薄羽绒 ×1（塔县早晚、长途车上）
- [ ] 外层：冲锋衣或防风外套（帕米尔风大）
- [ ] 厚羽绒服（D2—D3 塔县早晚，可 4 人拼 2 件）
- [ ] 长裤 ×2（一条厚一条薄）、秋裤 ×1（塔县）
- [ ] 舒适运动鞋/徒步鞋（峡谷栈道碎石多）
- [ ] 拖鞋（民宿/长途车上）
- [ ] 帽子（防晒硬檐帽 + 保暖毛线帽各 1）、围巾/魔术头巾
- [ ] 袜子内衣按天配 + 备用 1 套

## 防晒与护肤（南疆干燥 + 紫外线强）

- [ ] SPF50+ 防晒霜、润唇膏（必备，人人喊香）
- [ ] 保湿面霜/身体乳（干燥到怀疑人生）
- [ ] 太阳镜（帕米尔雪山反光强烈，必带）
- [ ] 湿巾、纸巾

## 沙漠专项（D5—D6 · N39）

- [ ] 沙套/鞋套（或旧运动鞋，烫沙进鞋很磨脚）
- [ ] 魔术头巾/口罩（防沙防晒两用）
- [ ] 手机/相机防沙密封袋（滑沙后沙粒无孔不入）
- [ ] 头灯或小手电（营地夜行、拍星空对焦）

## 电子设备

- [ ] 手机 + 充电器、**充电宝 ≤20000mAh（可上飞机，不可托运）**
- [ ] 车载充电器（问师傅车上有无，自带更稳）
- [ ] 相机 + 长焦（拍雪山/人文）、广角（沙漠）、存储卡
- [ ] 无人机（**帕米尔部分区域禁飞**，景区遵规定飞）
- [ ] 插线板（民宿插座少，车内多口充电更实用）
- [ ] **离线地图**提前下载：喀什地区、塔什库尔干、莎车、麦盖提

## 药品与健康

- [ ] 便携氧气瓶 ×1—2/人（喀什购买 20—30 元/瓶；佰汇亿达可租氧气瓶/大氧气袋）
- [ ] 红景天（提前一周开始服）、布洛芬（高反头痛应急）
- [ ] 感冒药、肠胃药、退烧止痛、创可贴
- [ ] 晕车药（帕米尔盘山路多弯）
- [ ] 个人常用药（足量带齐，南疆药店覆盖一般）
- [ ] 保温杯（高原喝热水）

## 食品与其他

- [ ] 干粮零食（D2 白沙湖午餐为路餐；D4 480km 长途日备路餐）
- [ ] 士力架/巧克力/牛肉干
- [ ] 保温毯/雨伞（防雨防晒两用）
- [ ] 垃圾袋（高原与景区请无痕）
- [ ] 折叠行李袋（装干果手信返程）

## 打包分层建议

| 场景 | 放哪 |
|---|---|
| 边防证/身份证/充电宝 | 随身小包 |
| 羽绒服/保暖层 | 随车背包顶（D2—D4 帕米尔随时取用） |
| 托运箱 | 换洗衣物、多人份（每换一家酒店搬一次） |
| 随车常备 | 水、零食、纸巾、垃圾袋、薄外套（长途车厢空调） |
| D6（10/2）还车前 | 清理车内个人物品、加满油、随身小包带走贵重物 |
